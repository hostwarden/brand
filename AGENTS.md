# AGENTS.md

The Hostwarden brand: the tower mark, the wordmark, the lockups and
the social preview, all generated by one script.

## Commands

    python3 -m venv .venv
    .venv/bin/pip install -r requirements.txt
    .venv/bin/python src/generate.py
    git status --short svg png

CI runs the same generator and fails when `svg/` or `png/` differ
from what it produces. Run it locally before pushing.

## Rules

- Everything in `svg/` and `png/` is output. Change the geometry,
  the palette or the list of variants in `src/generate.py` and
  regenerate; never edit an output file by hand.
- The palette, the type and the rules for use are in `README.md`,
  and a change to them changes the README in the same commit.
- `TRADEMARKS.md` says who may use the marks and how. Do not loosen
  it without the maintainer's explicit word.
- Pushing to `main` directly and merging a pull request are the
  maintainer's steps. Force-push only your own pull request branch,
  with `--force-with-lease`.
- Wrap every `.md` file at 80 characters.
